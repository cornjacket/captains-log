# log

Personal log entries — my own writing about what's going on: what happened, what I was thinking,
status in my own words. Dated files, `YYYY-MM-DD-<slug>.md`.

This is **not** where tasks live. Trackable work — anything with a status, a checklist, or an
order — belongs in the task system under [`project/tasks/`](../project/tasks/); see
[`project/tasks/docs/USING.md`](../project/tasks/docs/USING.md).
